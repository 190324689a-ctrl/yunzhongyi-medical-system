# 云中医医务系统 — 需求梳理（来自小丁微信发来的《云中医需求文档.pdf》，3 页扫描件）

文档性质：医院医务系统招标参数功能需求，共约 25 个模块。

## 模块清单

### 第 1 页
1. **医师档案管理**：基本信息（执业、学历、职称、聘期、证书、证件照、进修、人员类别、最高学历）、一个界面全面展示、支持批量导入导出、支持多条件组合查询、手术分级授权、抗肿瘤处方权、麻醉药品处方权、精神药品处方权、手术分级授权（分级授权管理）、支持新增、修改、删除、批量导入、导出、查询等。
2. **休假执业管理**：医师休假、执业、进修、外出进修、手术分级授权等申请与审批流程，支持在线申请、审批、查询、统计；支持打印预览；支持多级审批。
3. **重点授权管理**：手术、麻醉、抗肿瘤、精神类等重点授权的申请、审批、查询、统计；支持批量导入、导出。
4. **医师考核管理**：医师定期考核、医师考核、医德考评、医疗质量考核；支持自定义考核模板、批量导入、评分统计、结果查询、导出。
5. **排班管理**：科室、门诊、住院、急诊排班；支持按科室、按人员、按时间排班；支持排班模板、批量排班、调班、代班；支持与 HIS 对接。
6. **MDT 管理**：多学科会诊管理，支持 MDT 申请、审批、记录、统计。
7. **医疗人员动态管理**：医疗人员动态、人员变动、人员调动、人员离职、人员退休等管理。
8. **放射人员管理**：放射人员档案、放射人员资质、放射人员培训、放射人员健康管理。
9. **委员会管理**：各类委员会（医疗质量、药事、院感、输血、病案等）管理，支持委员会换届、会议记录、决议管理。
10. **文件制度管理**：文件、制度、规范、流程管理；支持分类、版本、发布、作废、查询；支持在线阅读、下载。

### 第 2 页
11. **政策法规管理**：政策、法规、文件管理；支持分类、发布、查询、更新。
12. **医德医风管理**：医德医风档案、医德考评、医德医风投诉、医德医风表彰。
13. **质量检查与自查**：科室自查、院级检查、专项检查；支持检查模板、检查计划、检查记录、整改反馈。
14. **院级质量检查**：院级质量检查计划、检查记录、检查报告、整改跟踪。
15. **专项质量检查**：专项检查（如病历、处方、抗菌药物等）的计划、记录、报告、整改。
16. **核心记本**（核心制度 / 笔记本）：核心制度落实、记录、检查。
17. **检查改汇总**：检查问题汇总、整改汇总、统计分析。
18. **医疗技术分级管理**：医疗技术分级、准入、授权、档案管理。
19. **检查维护**：检查项目、检查标准、检查模板的维护。
20. **检查分类**：检查分类管理。
21. **检查模板**：检查模板管理。
22. **医疗分级管理**：医疗分级、医疗质量分级管理。
23. **新技术、新项目管理**：新技术、新项目申报、审批、立项、验收、推广；支持在线申报、专家评审、伦理审查。

### 第 3 页
24. **工作统计**：手术量、工作量、门诊量、住院量统计；支持按科室、按人员、按时间统计。
25. **三级医院医疗质量指标统计**：三级医院评审指标、医疗质量指标统计；支持按国家、省、市标准统计。
26. **医疗质量统计**：医疗质量指标、医疗安全指标、患者安全指标统计；支持图形化展示。
27. **医务系统完成统计**：医务系统各模块完成情况统计。
28. **医务系统设置**（23 项）：用户管理、角色管理、权限管理、科室管理、字典管理、参数设置、日志管理、数据备份、系统接口、消息提醒设置等；支持自定义、批量导入、导出；支持 3000+ 条知识库。
29. **消息提醒**：待办提醒、消息推送、短信提醒、站内消息；支持按角色、按人员推送。
30. **医疗工作简报**：工作简报生成、发布、统计；支持模板、自动生成、导出 PDF/Word。
31. **医务管理移动端**：移动端支持查看、审批、统计；支持 iOS/Android；支持消息推送。

## 技术选型（按小丁简历与深圳市场）
- 后端：Java + Spring Boot 3 + MyBatis-Plus + MySQL
- 前端：Vue 3 + Element Plus
- 部署：Docker Compose（一键启动）
- 先做骨架 + 通用底座（用户/角色/权限/科室/字典/审计日志）+ 第一个完整模块「医师档案管理」，其余模块按清单逐个实现。
